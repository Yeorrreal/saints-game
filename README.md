# 성인 만들기 · *A Medieval Dress-Up*

> *Iconographia* — 중세 도상학(iconography) 게임
> 옷·머리·지물(attribute)을 마네킹에 입혀, 그 조합이 어떤 성인을 가리키는지 발견하세요.

🔗 **플레이하기**: [yjrosie.github.io/saints-game](https://yjrosie.github.io/saints-game/)

---

## 콘셉트

중세 회화에서 성인은 얼굴이 아니라 **지물**로 식별됐다.
- 베드로는 천국의 **열쇠**를 들고
- 모세는 **십계명** 판을 안고
- 베로니카는 예수의 얼굴이 새겨진 **수다리움**을 펼치고
- 세례자 요한은 **낙타가죽 옷**과 **비둘기**(성령)와 함께 등장한다.

이 게임은 도상의 문법을 거꾸로 작동시킨다 — 플레이어가 직접 지물을 조합하며, 어떤 성인이 만들어지는지 본다. 7인의 성인을 모두 발견하면 끝.

## 플레이 방법

1. 가운데에 흩어진 **옷·머리·소품**을 왼쪽 마네킹에 드래그하거나 클릭
2. 우측 패널은 발견된 성인의 명단 — 처음에는 모두 `???`로 가려져 있음
3. 도상학적으로 일치하는 조합이 만들어지면 성인이 **발견**되고 라틴어 이름이 공개됨
4. `옷 벗기` / `전체 초기화` 버튼으로 새 조합 시도
